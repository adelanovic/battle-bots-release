Battle Bots 1.0.0 for Windows 10/11 (64-bit).

- Offline desktop game, robot editor, guided missions, and built-in example robots.
- Setup wizard with Start menu and desktop shortcuts and Windows uninstall support.
- Load and save .asm robot files.
- Updates are installed manually by running a newer installer; automatic updates are not enabled.

This build is unsigned, so Windows may display an unknown-publisher or SmartScreen prompt.
